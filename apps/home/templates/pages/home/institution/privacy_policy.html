2. Datos que tratamos y finalidad

{% if content_blocks.section_datos %}
{{ content_blocks.section_datos|richtext }}
{% else %}

El portal trata las siguientes categorías de datos personales:

  • Suscriptores al boletín informativo: correo electrónico, origen de la suscripción (landing, registro, perfil, administración), fecha de confirmación y estado de la suscripción. Finalidad: envío de avisos meteorológicos, noticias y novedades del Centro. Base legal: consentimiento del interesado (art. 6.1.a GDPR / normativa cubana equivalente).
  • Usuarios del panel de administración: nombre de usuario, correo, nombre y apellidos (perfil), avatar opcional, condición de usuario LDAP, preferencia de boletín. Finalidad: autenticación, autorización, gestión de contenidos, notificaciones internas. Base legal: ejecución de un contrato / obligación legal / interés legítimo.
  • Clientes comerciales: datos fiscales (REEUP, NIT, cuenta bancaria, agencia, registro comercial, dirección, teléfonos), tipo de cliente (natural/jurídica), representante legal. Finalidad: facturación, gestión de contratos, emisión de certificados, servicios contratados. Base legal: ejecución de contrato / obligación legal.
  • Facturación y pagos: datos de facturas (cliente, servicios, importes, fechas, estado), asignaciones de coste, cobros. Finalidad: cumplimiento de obligaciones tributarias y contables. Base legal: obligación legal.
  • Log de acceso y métricas técnicas (RUM): dirección IP anonimizada, user-agent, ruta solicitada, tiempo de respuesta, errores HTTP. Finalidad: monitorización de disponibilidad, rendimiento y seguridad del servicio. Base legal: interés legítimo (seguridad y calidad del servicio).

Los datos no se ceden a terceros salvo obligación legal o cuando sea necesario para la prestación del servicio contratado:

  • Entidades bancarias para la gestión de cobros y pagos.
  • Administración tributaria (ONAT) en cumplimiento de obligaciones fiscales.
  • Proveedores de infraestructura (alojamiento, correo) bajo cláusulas de encargado de tratamiento.

5. Plazos de conservación

{% if content_blocks.section_conservacion %}
{{ content_blocks.section_conservacion|richtext }}
{% else %}
  • Suscriptores: mientras la suscripción esté activa; tras la baja se conserva el correo y la prueba de consentimiento durante 4 años para acreditar el cumplimiento.
  • Usuarios del panel: mientras la cuenta exista; tras la baja se anonimizan los datos de perfil en 30 días.
  • Clientes y facturación: 10 años desde la finalización de la relación contractual, por obligación contable y tributaria.
  • Logs técnicos y métricas: 12 meses en bruto; agregados estadísticos sin datos personales se conservan indefinidamente.
{% endif %}

6. Derechos del titular

{% if content_blocks.section_derechos %}
{{ content_blocks.section_derechos|richtext }}
{% else %}

Tienes derecho a:

  • Acceder a tus datos personales.
  • Rectificar datos inexactos o incompletos.
  • Suprimir tus datos cuando ya no sean necesarios.
  • Limitar el tratamiento.
  • Oponerte al tratamiento (incluye marketing directo).
  • Portabilidad de los datos que nos hayas facilitado.
  • Retirar el consentimiento en cualquier momento (para tratamientos basados en consentimiento).

Para ejercer tus derechos, envía una solicitud a {{ contact_email }} indicando el derecho que ejercitas y adjuntando copia de tu documento de identidad.
