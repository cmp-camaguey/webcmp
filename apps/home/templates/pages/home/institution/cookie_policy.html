1. ¿Qué son las cookies?

{% if content_blocks.section_que_son %}
{{ content_blocks.section_que_son|richtext }}
{% else %}

Una cookie es un pequeño archivo de texto que un sitio web guarda en tu dispositivo cuando lo visitas. Permite que el sitio recuerde información sobre tu visita (por ejemplo, que hayas iniciado sesión o que ya hayas visto el banner de consentimiento).

Esta Política explica qué cookies usa este sitio, para qué sirve cada una y cómo puedes gestionar tu consentimiento. Complementa el Aviso de Privacidad.

{% endif %}

2. Categorías de cookies que usamos

{% if content_blocks.section_categorias %}
{{ content_blocks.section_categorias|richtext }}
{% else %}

Necesarias (siempre activas)

Esenciales para que el sitio funcione: mantener tu sesión autenticada, proteger formularios contra ataques CSRF y recordar tu elección de consentimiento. En el panel interno también se usa el estado de la barra lateral. No requieren consentimiento, porque sin ellas el sitio no puede prestar el servicio.

Analítica / Rendimiento (requieren consentimiento)

Usamos RUM (Real User Monitoring) para medir el rendimiento real que experimentan los visitantes: tiempos de carga (LCP, FCP), interactividad (INP), estabilidad visual (CLS), peso de recursos transferidos, y errores de JavaScript. Los datos se agregan y anonimizan (IP truncada, sin identificadores personales) y sirven exclusivamente para mejorar la calidad y disponibilidad del servicio. Solo se activan si das tu consentimiento.

Funcionales (requieren consentimiento, futuras)

Reservadas para futuras mejoras: recordar preferencias de visualización (tema, idioma), mapas interactivos, contenidos incrustados de terceros. Actualmente no hay cookies funcionales activas.

{% endif %}

4. Cómo gestionar tu consentimiento

{% if content_blocks.section_consentimiento %}
{{ content_blocks.section_consentimiento|richtext }}
{% else %}

Al visitar el sitio por primera vez, verás un banner de consentimiento en la parte inferior con tres opciones:

  • Aceptar todo: habilita analítica y funcionales.
  • Rechazar analítica: solo necesarias (RUM desactivado).
  • Configurar: elige categoría por categoría en el modal.

Tu preferencia se guarda en la cookie cookie_consent (y en localStorage como respaldo) durante 1 año. Puedes cambiarla en cualquier momento desde el enlace «Configurar cookies» en el pie de página, que vuelve a abrir el modal.

{% endif %}

5. Cómo desactivar o borrar cookies desde el navegador

{% if content_blocks.section_desactivar %}
{{ content_blocks.section_desactivar|richtext }}
